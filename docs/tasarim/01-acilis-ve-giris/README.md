## Kararlar ve notlar

Splash, Android 12+ SplashScreen API kurallarına göre çizildi: düz zemin, ortada ikon, altta isteğe bağlı marka görseli (yazı logo). Metin, animasyonlu illüstrasyon ya da yükleme çubuğu eklenemez; uygulama hazır olunca doğrudan giriş ya da tayfa ekranı açılır.

Google düğmesindeki G simgesi yer tutucu. Kodda Google'ın resmi Sign-In marka varlığı ve düğme stili (açık: beyaz + gri kenar, koyu: #131314) kullanılmalı.
