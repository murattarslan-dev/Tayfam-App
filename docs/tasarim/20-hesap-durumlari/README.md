## Kararlar ve notlar

Hesap durum ekranları (metinler mevcut): ortak düzen: küçük logo, büyük ikon kutusu, başlık, açıklama, altta birincil eylem. Koşullar güncellendi: iki 'oku' satırı (tarayıcıda açılır) + tek onay kutusu; işaretlenmeden 'Onayla ve devam et' pasif; ikincil 'Çıkış yap'. Zorunlu güncelleme: mango ikon, 'Google Play'de güncelle' (iOS'ta App Store metni sonra). Hesap kısıtlandı / kapatıldı: nar ikon, mevcut metin; tek eylem 'Çıkış yap'. Yaş engeli tasarımı ayrı (Kayit-Yas-Engeli).
